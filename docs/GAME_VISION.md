# 게임 비전

## 게임 한 줄 설명

장애물을 피하고 액션을 활용해 각 스테이지를 클리어하는, 아기자기하고 귀여운 픽셀아트 스타일의 2D 플랫폼 액션 웹게임.

## 핵심 방향

- 장르는 2D 플랫폼 액션 게임이다.
- 플레이어는 이동과 점프를 활용해 장애물을 피하며 스테이지를 클리어한다.
- 조작은 단순하고 직관적이어야 한다.
- 플레이 감각과 조작 반응성을 중요하게 생각한다.
- 짧은 시간에도 부담 없이 플레이할 수 있어야 한다.
- 전체적인 분위기는 밝고 아기자기하며 귀여워야 한다.

## 핵심 플레이 요소

- 좌우 이동
- 점프
- 장애물 회피
- 다양한 지형 활용
- 스테이지 진행
- 스테이지 클리어
- 추후 필요에 따라 간단한 액션 요소 추가

게임의 핵심은 복잡한 전투보다 이동, 점프, 장애물 회피와 스테이지 공략의 재미에 둔다.

## 아트 방향

픽셀아트는 이 게임의 핵심 요소다.

다음 방향을 유지한다.

- 귀엽고 아기자기한 픽셀아트
- 밝고 편안한 분위기
- 캐릭터의 실루엣이 명확해야 한다.
- 배경과 장애물을 쉽게 구분할 수 있어야 한다.
- 지나치게 사실적인 표현은 피한다.
- 작은 화면에서도 오브젝트를 쉽게 알아볼 수 있어야 한다.
- 캐릭터와 환경 전체의 픽셀 밀도와 스타일을 통일한다.
- 애니메이션은 과도하게 복잡하기보다 귀엽고 명확한 움직임을 우선한다.

## 디자인 방향

Claude Code가 게임의 주요 디자인 작업을 담당한다.

디자인 작업에서는 다음 원칙을 따른다.

- Claude의 디자인 관련 스킬을 적극적으로 사용한다.
- 가능한 경우 실제 브라우저에서 화면을 확인하면서 디자인한다.
- 게임 플레이 화면을 중심으로 디자인한다.
- UI가 게임 화면을 과도하게 가리지 않도록 한다.
- 버튼, HUD, 메뉴 등은 단순하고 직관적으로 만든다.
- 픽셀아트 스타일과 UI 디자인이 서로 어울리도록 한다.
- 디자인 결과는 실제 브라우저 환경에서 확인한다.

## 플랫폼

게임의 주요 실행 환경은 웹 브라우저다.

다음 조건을 만족해야 한다.

- 별도의 설치 없이 브라우저에서 실행할 수 있어야 한다.
- 데스크톱 웹 브라우저를 우선 지원한다.
- 최신 Chrome, Edge, Firefox 등의 브라우저에서 정상 작동하는 것을 목표로 한다.
- 웹 환경에서 안정적으로 사용할 수 있는 기술을 우선한다.
- 초기 로딩 시간이 지나치게 길어지지 않도록 한다.
- 이미지, 사운드 등의 에셋 용량을 관리한다.
- 브라우저에서 픽셀아트가 흐려지지 않도록 렌더링 방식을 관리한다.

## 언어

한국어는 필수 지원 언어다.

다음 조건을 지킨다.

- 메뉴
- 버튼
- 설정
- 튜토리얼
- 스테이지 이름
- 시스템 메시지
- 게임 내 안내문

등 모든 사용자 노출 텍스트에서 한국어를 정상 지원해야 한다.

추후 다른 언어를 추가할 수 있도록 사용자에게 보여지는 문자열을 코드에 직접 하드코딩하는 방식을 가능한 피한다.

텍스트는 별도의 로컬라이징 구조로 관리하는 것을 우선한다.

한글이 잘리거나 깨지지 않도록 UI 크기와 폰트를 설계한다.

## 기술 방향

웹게임이라는 목표를 최우선으로 고려한다.

기술 또는 게임 엔진을 선택할 때 다음 조건을 중요하게 본다.

- 웹 브라우저 실행이 쉬울 것
- 2D 게임 제작에 적합할 것
- 픽셀아트 렌더링에 적합할 것
- 빠르게 반복 개발할 수 있을 것
- Claude Code와 Codex가 코드를 쉽게 수정하고 테스트할 수 있을 것
- 브라우저에서 직접 테스트하기 쉬울 것

네이티브 환경에서만 사용할 수 있는 기능은 꼭 필요한 경우가 아니라면 피한다.

## 프로젝트 우선순위

우선순위는 다음과 같다.

1. 재미있는 이동과 점프 조작감
2. 기본 스테이지 플레이 완성
3. 브라우저에서 안정적인 실행
4. 귀엽고 일관된 픽셀아트
5. UI 및 게임 화면 디자인
6. 한국어 지원
7. 스테이지와 콘텐츠 확장

## 프로젝트 원칙

- 게임의 핵심 방향을 임의로 변경하지 않는다.
- 지나치게 복잡한 시스템을 초기에 추가하지 않는다.
- 플레이 가능한 결과물을 빠르게 만드는 것을 우선한다.
- 기능보다 플레이 감각을 중요하게 생각한다.
- 디자인은 실제 브라우저 화면을 기준으로 판단한다.
- 픽셀아트 스타일의 일관성을 유지한다.
- 새로운 기능을 추가할 때 웹 브라우저 실행에 문제가 없는지 확인한다.
