# Peaceful Streets

브라우저용 2D 플랫폼 액션 게임의 첫 플레이 가능 프로토타입입니다.

## 실행

프로젝트 루트에서 `npm run dev`(= `python3 -m http.server 8000 --bind 127.0.0.1`)를 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

휴대폰으로 확인할 때만 `npm run dev:lan`을 쓰고 같은 와이파이에서 `http://<컴퓨터 IP>:8000`으로 접속합니다. 이 서버는 프로젝트 폴더 전체(로컬 설정 폴더 포함)를 네트워크에 보여 주므로, 믿을 수 있는 네트워크에서 잠깐만 켜고 확인이 끝나면 끕니다. npm 의존성이나 빌드 과정은 없습니다. 자동 테스트는 `npm test`로 실행합니다.

## 조작

- 이동: ← → 또는 A D
- 점프: ↑, W 또는 스페이스
- 일시정지·복귀: Esc
- 메뉴 선택: ↑ ↓, Space 또는 Enter
- 스테이지 처음부터 다시 시작: R
- 소리 켜기·끄기: M (선택은 브라우저에 저장됩니다)

터치 화면에서는 화면 아래 방향 버튼으로 이동하고, `점프` 버튼으로 점프와 메뉴 선택을 합니다. ↑↓는 메뉴 이동, `Ⅱ`는 일시정지·돌아가기, `♪`는 소리 켜기·끄기입니다.
타이틀 또는 일시정지 화면의 설정 메뉴에서 소리와 화면 크기를 바꿀 수 있습니다. 화면 크기는 `자동`(기본)과 `작게` 중 고르며, 두 설정 모두 브라우저에 저장됩니다.

## 기술 구조

- `index.html`, `styles.css`: 브라우저 진입점과 기본 화면
- `src/main.js`: 키보드 입력, 화면 전환, 고정 시간 간격 게임 루프, 화면 배율
- `src/game.js`: 이동·점프·충돌·체크포인트·꽃 수집·경과 시간
- `src/audio.js`: Web Audio 기반 효과음과 소리 설정 저장
- `src/display.js`: 화면 배율 계산과 크기 설정 저장
- `src/settings-menu.js`: 설정 항목의 표시 순서와 동작 연결
- `src/stage.js`: 64타일 1-1의 지형, 가시, 이동 화분, 가로등 두 곳, 꽃, 도착점
- `src/art.js`, `src/render.js`, `src/text.js`: 목업 팔레트·스프라이트, Canvas 렌더링, 카메라, Galmuri 텍스트
- `locales/ko.json`, `src/locale.js`: 키 기반 한국어 문구

Canvas는 내부 해상도 480×270으로 그립니다. 창에 맞는 배율이 2 이상이면 정수 배율, 그보다 작으면 비정수 배율로 확대하며 픽셀 보간을 끕니다. 게임은 타이틀, 시작 배너, 플레이, 일시정지, 클리어 화면을 갖추고 있습니다. 1-1은 이동 → 구덩이 → 가시 → 체크포인트 → 발판과 이동 화분 → 계단 → 깃발 순서입니다. 그림은 목업 기반의 검토용 픽셀아트입니다.
