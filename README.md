# Peaceful Streets

한적한 동네 골목을 달리는 고양이의 이야기입니다. 가시와 식인식물 화분을 피해 골목 끝의 깃발까지 가 보세요. 가는 길에 핀 꽃을 전부 모으면 더 좋고요.

브라우저에서 바로 즐기는 픽셀아트 2D 플랫폼 게임으로, 지금은 첫 스테이지 **1-1 골목 입구**까지 만들었습니다.

**플레이하기:** https://peaceful-streets.vercel.app

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | ← → 또는 A D | ◀ ▶ 버튼 |
| 점프 | Space, ↑ 또는 W | 점프 버튼 |
| 2단 점프 | 공중에서 점프를 한 번 더 | 공중에서 점프 버튼을 한 번 더 |
| 일시정지 | Esc | Ⅱ 버튼 |
| 소리 켜기·끄기 | M | 스피커 버튼 |
| 처음부터 다시 | R | 일시정지 메뉴의 "다시 시작" |

점프는 짧게 누르면 낮게, 길게 누르면 높이 뜁니다. 가시나 화분에 부딪히거나 물에 빠지면 마지막으로 지나간 가로등에서 곧바로 다시 시작합니다.

메뉴는 키보드에서는 ↑ ↓로 고르고 Space나 Enter로 선택하며, 터치 화면에서는 항목을 직접 누르면 됩니다. 설정에서 소리와 화면 크기(자동·작게)를 바꿀 수 있고, 고른 값은 브라우저에 저장됩니다.

## 로컬에서 실행하기

빌드 과정도, 설치할 패키지도 없습니다. Python만 있으면 됩니다.

```
npm run dev
```

브라우저에서 http://localhost:8000 을 열면 됩니다. 테스트는 `npm test`로 돌립니다.

휴대폰으로 확인하고 싶다면 `npm run dev:lan`을 실행하고 같은 와이파이에서 `http://<컴퓨터 IP>:8000`으로 접속하세요. 다만 이 서버는 프로젝트 폴더 전체를 네트워크에 공개하므로, 믿을 수 있는 네트워크에서 잠깐만 켜 두는 것이 좋습니다.

## 만든 방식

별도의 엔진이나 라이브러리 없이 Canvas 2D와 ES 모듈만으로 만들었습니다.

- 화면은 480×270 크기로 그린 뒤 창에 맞게 키웁니다. 2배 이상일 때는 정수 배율만 써서 픽셀이 흐려지지 않게 했습니다.
- 캐릭터와 배경은 모두 직접 그린 픽셀아트 스프라이트이고, 이미지를 불러오지 못하면 코드로 그린 그림이 대신 나옵니다.
- 화면에 보이는 문구는 모두 `locales/ko.json`에 모아 두었습니다.

| 파일 | 하는 일 |
|---|---|
| `src/main.js` | 입력, 화면 전환, 게임 루프, 화면 배율 |
| `src/game.js` | 이동과 점프, 충돌, 체크포인트, 꽃 모으기 |
| `src/stage.js` | 1-1의 지형과 장애물, 꽃 17개의 위치 |
| `src/render.js`, `src/camera.js` | 화면 그리기, HUD와 메뉴, 카메라 |
| `src/sprites.js`, `src/assets.js` | 스프라이트 시트 불러오기와 그리기 |
| `src/art.js` | 코드로 그린 대체 그림 |
| `src/text.js`, `src/locale.js` | 픽셀 폰트 글자 그리기, 한국어 문구 |
| `src/audio.js`, `src/display.js`, `src/settings-menu.js` | 효과음, 화면 크기, 설정 메뉴 |

## 에셋과 폰트

- `npm run assets:p1`, `npm run assets:p2`: 픽셀아트 PNG를 `assets/generated/`에 새로 만듭니다. 확인한 뒤 `assets/sprites/`로 옮겨 씁니다.
- `npm run assets:icon`: 브라우저 탭 아이콘을 만듭니다.
- 폰트는 [Galmuri](https://github.com/quiple/galmuri)에서 게임에 쓰는 글자만 추려 "PS Pixel"이라는 이름으로 넣었습니다. 원본 폰트 라이선스(SIL OFL)의 예약 이름 규정 때문에 이름을 바꿨으며, 게임은 이 폰트를 브라우저 글꼴로 쓰지 않고, 글자 픽셀을 뽑아 둔 `src/font-data.js`로 직접 그립니다. 그래서 휴대폰에 설정한 글꼴과 상관없이 똑같이 보입니다. 문구에 새 글자를 넣었다면 `scripts/subset-fonts.py`, `npm run assets:font`를 차례로 다시 실행해야 합니다.
