배율
1×는 실제 픽셀 크기입니다. 작은 창에서 오브젝트가 구분되는지 볼 때 씁니다.

이 화면은 src/의 실제 게임 코드를 그대로 묶은 것입니다. 게임을 고친 뒤 python3 mockup/build-review.py로 다시 만들면 늘 같아집니다.

지금까지 반영한 것

  1. 고양이 16×16, → 누르면 오른쪽을 보고 꼬리가 왼쪽
  2. HUD는 외곽선 글자, 꽃은 모은 개수 / 전체. 전부 모으면 노랗게 반짝이고 클리어 화면에 배지
  3. 구체적인 골목 배경: 산 능선, 아파트, 빌라 물탱크, 기와집, 차양 가게, 빨랫줄, 담장
  4. 빨간 식인식물 화분, 가로등 위 "체크포인트" 이름표
  5. 2단 점프(발밑 구름 + 회전), 짧게 누르면 낮게, 2단 점프로만 닿는 보너스 꽃 2개
  6. 스테이지 시작·부활 때 고양이 위치에서 픽셀 원이 열리는 화면 전환
  7. 설정 화면: 키캡 조작 안내, 소리 스위치, 화면 크기
  8. 휴대폰: 메뉴 직접 누르기, 픽셀 패널 버튼, 가로 화면에서 버튼이 게임을 가리지 않게

진행 중

  1. 방향을 바꿀 때 화면이 크게 흔들리는 문제: 앞보기 거리를 줄이고 천천히 바뀌게 고칠 예정입니다 (Codex).
  2. 정식 픽셀아트 에셋: 사양(docs/ASSET_SPEC.md)을 작성했고, 지금 그림을 바탕으로 다듬을 예정입니다.
